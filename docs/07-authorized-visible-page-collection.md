# 授权页面可见信息整理标准

更新日期：2026-05-15

## 1. 目标说明

本标准用于后续“合规插件 / 授权页面可见信息整理 / 平台风向监控”的前置设计。

当前阶段只定义标准，不开发插件，不接抖音自动抓取，不写爬虫，不修改现有采集逻辑。

核心原则：

- 只整理用户主动打开、已授权、当前页面已经可见的信息。
- 不读取不可见、未授权或受限制的数据。
- 不绕过登录、验证码、权限限制或平台风控。
- 不自动操作平台账号，不发布内容，不发送私信，不修改账号设置。
- 所有整理结果先进入人工确认或分析预览，再决定是否进入账号监控池、爆款拆解池或内容建议流程。

## 2. 允许读取的数据范围

允许整理以下用户已授权、当前页面可见的信息：

- 用户已登录后当前页面可见的信息。
- 用户手动打开的账号主页。
- 用户手动打开的视频页。
- 用户手动打开的搜索结果页。
- 用户自己账号后台可见数据。
- 用户手动导出的 CSV、表格、截图、文本。
- 用户手动框选、复制或确认发送给系统的页面文本。
- 页面上已经展示的公开互动数据，如播放、点赞、评论、收藏、转发等。

## 3. 禁止读取的数据范围

不得整理或尝试获取以下内容：

- 当前页面没有显示的信息。
- 用户未授权的信息。
- 登录前不可见、权限外或受限制的数据。
- 需要绕过验证码、扫码、安全验证或风控才能看到的数据。
- 平台隐藏接口、内部 API、未公开接口或非页面可见数据。
- 批量翻页、批量采集、后台静默抓取或自动遍历账号/视频。
- 私信、通知、联系人、粉丝列表等敏感数据，除非用户明确打开并逐条授权整理当前可见内容。
- 任何绕过平台安全机制才能获取的数据。

## 4. 可整理字段

授权页面可见信息整理时，优先整理以下字段：

| 字段 | 说明 |
| --- | --- |
| 平台 | 抖音 / 小红书 / 视频号 / B站 / 快手 / 其他 |
| 账号名 | 当前页面可见的账号名称 |
| 主页链接 | 当前页面可见或浏览器地址栏中的账号主页链接 |
| 视频链接 | 当前页面可见或浏览器地址栏中的视频链接 |
| 标题 | 当前视频、图文或搜索结果标题 |
| 发布时间 | 页面可见的发布时间 |
| 视频播放量 | 页面可见的播放量 |
| 点赞数 | 页面可见的点赞数 |
| 评论数 | 页面可见的评论数 |
| 收藏数 | 页面可见的收藏数 |
| 转发数 | 页面可见的转发数 |
| 视频文案 | 页面可见的视频正文、简介或描述 |
| 封面文字 | 页面可见或用户补充的封面文字 |
| 前3秒钩子 | 从标题、开头文案、画面或用户备注中整理 |
| 评论区高频问题 | 当前页面可见评论中反复出现的问题 |
| 选题类型 | AI工具 / 内容生产 / 变现 / 认知观点 / 热点跟进 / 案例拆解 / 其他 |
| 爆款原因 | 根据可见数据、标题结构、情绪点、利益点和评论反馈初步判断 |
| 适合 AI先锋 的角度 | 是否能服务流量、信任、转化、私信、直播、799 元 AI口播智能体承接 |
| 适合 AI先锋者 的角度 | 是否能服务高认知、趋势判断、误区拆解、个人实战、长期信任、方法论沉淀 |
| 是否适合进入爆款拆解池 | 是 / 否 / 待人工确认 |
| 是否适合进入今日内容建议 | 是 / 否 / 待人工确认 |

## 5. 输出位置建议

后续插件或页面整理工具可以优先输出到以下位置：

- `data/manual/visible_page_observations.csv`
- `outputs/monitoring/visible_page_summary_YYYY-MM-DD.md`
- `outputs/monitoring/viral_video_breakdown_YYYY-MM-DD.md`

当前阶段只定义输出位置建议，不创建这些文件。

## 6. 人工协作流程

标准流程：

1. 用户手动打开目标页面。
2. 用户确认已经登录并授权整理当前页面可见信息。
3. 系统只读取当前页面已经显示的内容。
4. 系统整理字段并生成分析预览。
5. 用户确认是否进入账号监控池、爆款拆解池或今日内容建议。
6. 系统记录需要人工补充的缺失字段。

遇到以下情况时必须停止：

- 未登录。
- 需要扫码。
- 需要验证码。
- 需要二次授权。
- 触发平台风控。
- 页面提示访问受限。
- 页面信息不可见。
- 用户未明确授权整理当前页面。

停止后标准动作：

1. 不尝试绕过。
2. 不继续自动读取。
3. 记录卡点原因。
4. 提示用户需要手动处理什么。
5. 用户处理完成并重新确认后，再继续整理当前可见信息。

## 7. 和现有系统衔接

授权页面可见信息整理结果可以进入以下流程：

- 进入账号监控池候选：用于补充账号名、平台、主页链接、代表视频、关注理由和监控等级。
- 进入爆款拆解池候选：用于补充视频链接、标题、数据表现、前3秒钩子、爆款原因和可借鉴点。
- 进入 `ai_daily_brief`：作为今日内容建议、风险提醒、信息源摘要或明日观察方向的补充素材。
- 进入 `daily_learning_log`：记录哪些页面信息被整理、哪些选题被采用、哪些被放弃及原因。
- 进入 `weekly_review`：复盘本周哪些可见页面素材质量高、哪些内容方向反复出现。
- 进入 `monthly_methodology_upgrade`：沉淀月度平台风向、双账号内容方法论和长期标准。

所有进入正式表格或报告的内容，都应保留来源说明和人工确认状态。

## 8. 账号页整理标准

用户打开账号主页后，可以整理：

- 平台。
- 账号名。
- 主页链接。
- 账号简介。
- 当前页面可见的视频数量或代表视频。
- 当前页面可见的粉丝、获赞、关注等数据。
- 最近可见内容主题。
- 账号定位初判。
- 值得关注原因。
- 更适合 AI先锋 / AI先锋者 / 双账号均可。
- 是否建议进入账号监控池。
- 需要用户补充的信息。

账号页整理结果默认先进入候选，不直接自动入库。

## 9. 视频页整理标准

用户打开视频页后，可以整理：

- 平台。
- 账号名。
- 主页链接。
- 视频链接。
- 标题。
- 发布时间。
- 视频播放量。
- 点赞数。
- 评论数。
- 收藏数。
- 转发数。
- 视频文案。
- 封面文字。
- 前3秒钩子。
- 评论区高频问题。
- 核心冲突。
- 情绪点。
- 利益点。
- 结尾 CTA。
- 爆款原因初判。
- 适合 AI先锋 的改写角度。
- 适合 AI先锋者 的改写角度。
- 是否适合进入爆款拆解池。
- 是否适合进入今日内容建议。

视频页整理必须只学习结构、选题和方法，不复制原作者核心表达，不洗稿。

## 10. 搜索结果页整理标准

用户打开搜索结果页后，可以整理当前页面可见的：

- 搜索关键词。
- 平台。
- 可见结果标题。
- 可见账号名。
- 可见互动数据。
- 可见发布时间。
- 可见链接。
- 反复出现的选题方向。
- 当前平台风向初判。
- 是否值得进一步人工打开单条视频页。

搜索结果页整理不得自动翻页、批量遍历或绕过平台限制。

## 11. 用户自己账号后台整理标准

用户打开自己账号后台后，可以整理当前页面可见的：

- 内容标题。
- 发布时间。
- 播放量。
- 点赞数。
- 评论数。
- 收藏数。
- 转发数。
- 转粉。
- 私信数。
- 直播转化情况。
- 成交情况。
- 用户主观判断：有效 / 一般 / 不适合。

这些数据可以用于账号数据复盘、`daily_learning_log`、`weekly_review` 和 `monthly_methodology_upgrade`。

后台数据必须由用户主动打开并授权整理，不得静默访问。

## 12. 如何避免违规爬虫

必须遵守：

- 不自动访问用户没有打开的页面。
- 不自动翻页采集。
- 不批量遍历账号、视频或搜索结果。
- 不调用隐藏接口。
- 不绕过登录、验证码、权限限制或风控。
- 不读取当前页面不可见的数据。
- 不保存敏感个人信息。
- 不自动发布、评论、点赞、私信或修改平台设置。
- 不把授权页面整理工具做成平台抓取器。

允许的定位是：用户主动打开页面后，系统帮用户整理当前页面可见信息。
