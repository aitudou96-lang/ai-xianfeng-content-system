## 日报输出结构

每日输出建议按以下顺序：

- 一、AI先锋 今日变现内容包：至少 1 条流量内容、1 条信任内容、1 条转化内容
- 二、AI先锋者 今日IP内容包：至少 1 条流量型认知内容、1 条信任型方法论内容、1 条长期人设内容
- 三、今天最建议拍的4条
- 四、今日信息源摘要
- 五、今日不建议做的内容
- 六、今日读取失败的信息源
- 七、明天建议观察什么
- 八、合规边界

“今天最建议拍的4条”必须固定包含：

- AI先锋 2 条：1 条流量/信任优先，1 条转化优先
- AI先锋者 2 条：1 条流量型认知优先，1 条长期信任/人设优先

每条必须包含：

- 标题
- 前3秒
- 账号
- 内容目的
- 拍摄形式
- 结尾方式
- 是否提产品
- 为什么今天优先拍
- 拍摄难度
- 预计价值

结构约束：

- 已进入 AI先锋 今日变现内容包的流量、信任、转化内容，不再在日报后半部分重复用“今日适合做流量/信任/转化的内容”重新展开
- 日报后半部分只保留信息源摘要、风险/不建议内容、读取失败、明日观察和合规边界
- “两个都适合”只作为底层判断保留；日报推荐区必须给出更明确的主账号归属
- 如果一条素材两个账号都能用，日报里必须拆成“AI先锋版本角度”和“AI先锋者版本角度”，不能只写“双账号均可”
- 拍摄建议不能固定套用同一个句式；需要按账号定位、内容目的和素材类型变化表达

## 内容建议输出结构

每条内容建议必须包含：

- 标题方向
- 开头钩子
- 核心观点
- 内容结构
- 适合账号
- 内容目标
- 驱动类型
- 推荐形态
- 是否承接 AI口播智能体
- 承接方式：私信 / 直播 / 教程演示 / 案例拆解 / 观点铺垫 / 暂不承接
- 产品连接句
- 不适合承接原因
- 下一步动作
- 一句话拍摄建议

AI先锋 输出补充要求：

- 每日必须给出流量、信任、转化各 1 条候选
- 可以承接 799 元 AI口播智能体，但必须写清承接方式和结尾 CTA
- 内容目标围绕精准流量、信任建立、私信/直播/教程/案例转化

AI先锋者 输出补充要求：

- 每日必须给出流量型认知、信任型方法论、长期人设各 1 条候选
- 默认不强提 799 产品
- 内容目标围绕 AI认知、AI变现观察、趋势判断、误区拆解、个人实战记录、编导和运营方法论
- AI先锋者 与 AI先锋 同等重要，不作为变现号附属

## 持续学习和自我进化机制输出标准

本章节只定义持续学习机制的输出标准，用于后续逐步建立每日学习、每周复盘、每月方法论升级的最小闭环。当前阶段不开发插件，不接抖音抓取，不改账号监控池，不修改 ai_daily_brief 生成逻辑，不创建新模块。

### 每日学习记录 daily_learning_log

每日学习记录用于沉淀系统当天的输入、筛选、推荐和人工反馈，重点记录“为什么推荐”和“为什么放弃”，不替代 ai_daily_brief。

建议字段：

| 字段 | 说明 |
| --- | --- |
| 日期 | 记录当天日期 |
| 今日采集信息源 | 当天系统实际读取或尝试读取的信息源 |
| 有效信息源 | 当天成功读取且产出有效素材的信息源 |
| 失败信息源 | 当天读取失败、为空、权限受限或需要人工协助的信息源 |
| 进入 AI先锋 内容包的选题 | 被归入 AI先锋 流量、信任、转化内容包的选题 |
| 进入 AI先锋者 内容包的选题 | 被归入 AI先锋者 流量型认知、信任型方法论、长期人设内容包的选题 |
| 进入今天最建议拍的4条的选题 | 最终进入 4 条优先拍摄建议的选题 |
| 被放弃的选题 | 当天采集到但没有进入推荐区的选题 |
| 放弃原因 | 弱相关、风险不明、时效不足、无法连接账号定位、重复、缺少人工核验等 |
| 今日推荐判断依据 | 系统判断优先级时使用的主要依据，如账号定位、素材强度、转化可能、信任价值、风险边界 |
| AI先锋 今日学习到什么 | 关于流量、信任、转化、私信、直播、799 元 AI口播智能体承接的新增判断 |
| AI先锋者 今日学习到什么 | 关于高认知、趋势判断、行业误区、个人实战、长期信任、方法论沉淀的新增判断 |
| 用户人工反馈入口 | 用户补充真实发布结果、数据表现和主观判断的位置 |

用户人工反馈入口至少支持补充：

- 哪条内容发了
- 播放量
- 点赞
- 评论
- 收藏
- 私信数
- 直播转化情况
- 成交情况
- 用户主观判断：有效 / 一般 / 不适合

### 每周复盘 weekly_review

每周复盘用于把 7 天的学习记录汇总成下周内容策略，不直接替代人工判断，也不把单日异常数据当成长期规律。

建议字段：

| 字段 | 说明 |
| --- | --- |
| 周期 | 记录复盘对应周 |
| 本周质量最高的信息源 | 按有效素材数量、相关性、可拍价值和风险可控性判断 |
| 本周反复出现的内容方向 | 多次出现且与双账号定位相关的热点、痛点、趋势或方法论 |
| AI先锋 更适合流量的方向 | 更容易带来精准流量、评论、私信或直播进入的方向 |
| AI先锋 更适合转化的方向 | 更容易自然连接教程、案例、私信、直播和 799 元 AI口播智能体的方向 |
| AI先锋者 更适合认知的方向 | 更适合输出高认知观点、趋势判断、机会判断和误区拆解的方向 |
| AI先锋者 更适合长期信任的方向 | 更适合沉淀个人实战、方法论、行业观察和长期人设的方向 |
| 应该减少的选题 | 数据弱、反馈差、风险高、重复、偏离账号定位或过度卖货的选题 |
| 下周内容策略建议 | 下周 AI先锋 和 AI先锋者 的内容比例、重点选题和观察方向 |

### 每月方法论升级 monthly_methodology_upgrade

每月方法论升级用于把当月行业变化、平台风向、账号反馈和内容结果沉淀为长期标准，避免系统只追短期热点。

建议字段：

| 字段 | 说明 |
| --- | --- |
| 月份 | 记录升级对应月份 |
| 本月 AI 行业变化 | 当月对普通人、自媒体人、知识付费从业者和个体创业者有影响的 AI 变化 |
| 本月内容平台风向变化 | 当月短视频、直播、私信转化、内容表达方式的变化 |
| AI先锋 变现内容方法论升级 | 关于流量、信任、转化、私信、直播和 799 元 AI口播智能体承接的新增规则 |
| AI先锋者 IP 内容方法论升级 | 关于高认知观点、趋势判断、行业误区、个人实战和长期信任的新增规则 |
| 本月产品承接机会 | 哪些场景更适合自然承接产品、咨询、陪跑、课程或合作 |
| 下月重点观察趋势 | 下月需要持续跟踪的 AI 行业变化、平台风向和用户需求 |
| 需要沉淀进长期标准的方法论 | 应写入后续内容标准、选题标准、话术标准或账号策略的结论 |

### 双账号学习边界

- AI先锋 学习重点是流量、信任、转化、私信、直播、799 元 AI口播智能体承接。
- AI先锋者 学习重点是高认知、趋势判断、行业误区、个人实战、长期信任、方法论沉淀。
- AI先锋者 不能被学习机制带偏成卖货号。
- 不能让所有学习结论都导向 799 产品。
- 双账号学习结论必须分别记录，不能用 AI先锋 的变现逻辑覆盖 AI先锋者 的 IP 逻辑。
